# AUTO BONGO 2.0.8

Triniidadii Productions

[Download the latest Windows release](../../releases/latest).

## Installation

1. Close Bongo Cat and AUTO BONGO.
2. Download and fully extract `AUTO-BONGO-V2.0.8-Windows-x64.zip`.
3. Run `Install AUTO BONGO V2.bat` and approve installation.
4. Open Bongo Cat and AUTO BONGO. Enable Beat, Collect or Emoji as needed.

The installer checks the game interface and preserves an original assembly backup. It does not install a virtual controller driver.

## Background automation

Automation runs through the bridge inside Bongo Cat. The game does not need to be focused. AUTO BONGO does not send automated mouse, keyboard or controller input to other applications.

Collection checks both chest shops. Emote automation uses equipped reusable emotes. Keyboard shortcuts operate while AUTO BONGO is focused.

## After a game update

If the game update removes the bridge, a notice explains that it needs reinstalling. Close both applications and rerun the current full installer. Opening only the EXE does not restore the connection. The old partial repair routine is disabled.

If the current installer reports an unsupported game update, send the error and game version to Triniidadii Productions. Do not repeatedly install an older package.

## Window and rewards

Use the taskbar to minimize and restore either layout. AUTO BONGO no longer stays above other applications. Close exits the app.

Enable listening in Settings to count local Spotify desktop playback. Only recognized Triniidadii artist playback earns the artist rewards. Pauses and skipped audio do not count. Share rewards count saved cards, not verified friends. All unlocks are AUTO BONGO cosmetics.

## Reporting an issue

Send the steps, expected result and actual result. Export logs creates a diagnostics ZIP for you to review and share through [Discord](https://discord.gg/VGsZUDsrj9). It does not submit files automatically.

## Removal

Use Windows Installed Apps to uninstall AUTO BONGO. The original game assembly backup is restored when the installed patch is still present. Existing third party drivers are not removed.
